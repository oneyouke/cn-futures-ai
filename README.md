# cn-futures-ai
国内商品期货 AI 研究、回测与模拟交易系统。

当前版本是离线回测原型，尚无 AI 模型、实时行情或实盘下单接口。

## 快速开始
安装 Python 3.10 或更新版本，无第三方依赖。在项目目录运行：

```bash
python futures.py --test
python futures.py --demo
```

Windows 如果找不到 python，可改用 py；macOS/Linux 可尝试 python3。

演示使用合成价格，包含非交易日。参数与收益只用于验证程序，不代表真实合约、历史表现或盈利预期。

## 已实现
- 单一合约 OHLC 导入，价格范围和时间顺序校验。
- 双均线多空信号，收盘产生信号、下一根开盘执行，每次一手。
- 开仓、平仓、平今的固定费用与成交金额费率，方向性滑点。
- 开仓保证金占用上限、收盘止损及按数据源交易日统计的亏损停开。
- 交易流水、权益曲线、费用和最大回撤汇总。

## 真实数据
CSV 表头必须包含：
```text
timestamp,trading_day,open,high,low,close
```

timestamp 使用无时区的北京时间 ISO 格式；trading_day 为 YYYY-MM-DD，必须由数据源提供，夜盘不能直接按自然日推算。仅使用单一实际合约，不能直接拼接主力连续合约。

复制 contract.example.json 为 contract.local.json，按目标合约和期货公司参数填写，然后运行：
```bash
python futures.py --csv data/bars.csv --config contract.local.json --out results
```

示例配置全部为演示假设。multiplier 为每手乘数；tick 为最小变动价位；slippage_ticks 为每次成交滑点跳数。费用为“每手固定金额 + 成交价 × 乘数 × 费率”；百分比须写成小数。当前模型不支持随日期变更参数。

## 输出
- results/summary.json：资金、收益、费用、回撤及所用参数。
- results/trades.csv：成交方向、价格、费用、已实现盈亏和原因。
- results/equity.csv：每根收盘权益、持仓及当日停开状态。

重复运行同一输出目录会覆盖结果。realized_pnl 不含手续费，净收益应扣除所有开平仓费用。最大回撤按收盘权益计算。

## 模型边界
止损和日亏损条件均在收盘检查，下一开盘执行，不能保证实际损失被限制在阈值内。止损退出后可在后续信号重新入场；每日亏损停开至下一交易日。末根收盘按滑点强制清仓是回测终止约定。

不模拟交易日历、涨跌停排队、成交量约束、盘中路径、强平、结算价结算和换月；目前只检查顺序/重复和价格有效性，不能自动判断缺失交易时段。保证金仅作开仓准入判断。接入真实交易前需完善这些模块。

## 测试
`python futures.py --test` 验证盈亏核算、下一开盘执行、资金不足拦截、重复时间拒绝，以及修改未来行情不影响此前权益。GitHub Actions 在推送和 PR 时运行测试及演示。
